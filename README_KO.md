# SMD 부품 관리

칩 저항, 칩캡(MLCC), 탄탈 커패시터, 코일, 다이오드를 브라우저에서 함께 관리하는 웹 앱입니다. Go 서버가 한국어 화면을 포함하고, 재고는 SQLite 파일 하나에 저장됩니다.

## 공개 주소

이 저장소는 아직 Render나 Fly에 배포되어 있지 않습니다. 공개 URL은 배포가 끝난 뒤에 해당 대시보드에 표시됩니다. 그 주소로 접속하면 아래 로컬 화면과 같은 목록이 열리고, 등록·수정·삭제·검색·분류/크기 필터·XLSX/CSV/JSON 가져오기와 내보내기를 사용할 수 있습니다.

Render에 올릴 때는 저장소 루트의 `render.yaml` Blueprint를 사용합니다. 플랜은 무료(`free`)이고 지역은 싱가포르입니다. 디스크는 붙이지 않습니다.

1. Render에서 이 GitHub 저장소를 연결하고 Blueprint를 적용합니다.
2. 서비스는 `0.0.0.0:$PORT`에 붙습니다. `PORT`는 Render가 넣어 주고, 상태 확인 경로는 `/healthz`입니다.
3. 데이터베이스는 컨테이너 안의 `./data/smd_parts.db`입니다. 이미지에 103건 DB가 들어 있으므로 별도 복사나 유료 디스크가 필요 없습니다.
4. 배포가 끝나면 Render 대시보드의 URL로 접속합니다. 이 저장소에는 공개 URL을 적어 두지 않습니다. `/healthz`는 `{"ok":true,"count":...}`를 반환합니다.

무료 인스턴스의 디스크는 임시입니다. 재시작이나 재배포가 나면 컨테이너가 다시 만들어지고, 그 사이 추가·수정·삭제한 내용은 사라집니다. 재고는 이미지에 구워 둔 103건으로 돌아갑니다. 남길 내용이 있으면 재시작 전에 XLSX, CSV, JSON으로 내보내세요.

## 로컬 실행

Go 1.22 이상이면 됩니다. SQLite 드라이버는 순수 Go라 CGO가 필요 없습니다.

```sh
go run .
```

브라우저에서 http://127.0.0.1:8080 을 엽니다. 서버는 `0.0.0.0:8080`에 붙습니다.

| 환경 변수 | 기본값 | 의미 |
| --- | --- | --- |
| `PORT` | `8080` | 수신 포트 |
| `SMD_DB` | `./data/smd_parts.db` | SQLite 파일 경로 |
| `SMD_SEED_DB` | (없음, 바이너리에 포함된 DB) | 대상 파일이 없을 때만 복사할 시드 |
| `SMD_OPEN_BROWSER` | 데스크톱만 자동 | `1`이면 로컬에서 브라우저를 엽니다. `0`이면 열지 않습니다. |

Windows와 macOS에서는 클라우드 환경이 아니고 `SMD_OPEN_BROWSER`를 끄지 않았으면 브라우저를 엽니다. Linux에서는 `SMD_OPEN_BROWSER=1`일 때만 엽니다. Render, Fly처럼 클라우드로 감지되면 어떤 값이든 브라우저를 열지 않습니다.

```sh
CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o smd-parts .
PORT=8080 SMD_DB=./data/smd_parts.db ./smd-parts
```

Docker:

```sh
docker build -t smd-parts .
docker run --rm -p 8080:8080 smd-parts
```

이미지의 작업 디렉터리는 `/app`이고, `data/smd_parts.db`가 `/app/data/smd_parts.db`로 복사됩니다. `SMD_DB`를 지정하지 않으면 `./data/smd_parts.db`를 엽니다. 컨테이너를 지우거나 다시 만들면 수정분은 사라지고 이미지에 들어 있던 103건으로 돌아갑니다.

## 같이 쓰는 데이터베이스

실행 중인 서버 안에서는 모든 사용자가 SQLite 파일 하나를 봅니다. 화면은 약 4초마다 목록을 다시 읽고, 다른 사람이 저장한 내용이 곧 나타납니다. 같은 품목을 동시에 수정하면 나중에 저장한 값이 남습니다.

Render 무료 플랜에서는 그 파일이 컨테이너 안에만 있습니다. 재시작이나 새 배포가 나면 이미지에 포함된 103건으로 돌아갑니다. 남길 내용은 화면에서 내보내거나, 서버를 멈추기 전에 `SMD_DB` 파일을 복사하세요.

로그인 기능은 없습니다. 주소를 아는 사람은 누구나 재고를 바꿀 수 있으니, 공개 인터넷에 올릴 때는 그 점을 염두에 두세요.

## 들어 있는 재고

`data/smd_parts.db`가 실제 재고입니다. 처음 기준으로 103건입니다.

| 분류 | 건수 |
| --- | ---: |
| 칩 저항 | 69 |
| 칩캡(MLCC) | 26 |
| 탄탈 커패시터 | 5 |
| 코일 | 2 |
| 다이오드 | 1 |

서버는 시작할 때 `seed/parts.json`을 읽지 않습니다. 그 파일은 예전 추출본 68건이고, 코일·다이오드와 나중에 추가된 품목은 SQLite에만 있습니다. DB 파일이 이미 있으면 행을 다시 넣거나 지우지 않습니다. 파일이 없거나 SQLite 형식이 아닐 때만 포함된 시드 DB를 한 번 복사합니다.

확인:

```sh
CGO_ENABLED=0 go test ./...
```

`/healthz`의 `count`가 첫 실행에서 103이어야 합니다.
